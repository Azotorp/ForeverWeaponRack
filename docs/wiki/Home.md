# ForeverWeaponRack

A weapon set swapper for **WoW Forever** (1.60.x). Save sets of Main Hand, Off Hand, Ranged and Ammo, bind each set to a key, and swap them live in combat.

> **EXPERIMENTAL.** ForeverWeaponRack has not been confirmed to work fully in WoW Forever yet. Equipping in combat through the add-on API is still being tested. Treat the add-on as experimental until the [[Testing Checklist]] is done and every feature works as intended.

It works for any class: sword and board, two-handers, dual wield, staves, wands, ranged weapons, and relics (librams, idols, totems). It is built for weapon swaps in combat and in raids. Full gear sets are left to add-ons like ItemRack.

## Quick facts

- Open the window with `/fwr`, `/weaponrack`, `/wr`, or the minimap button.
- Sets, set keys and the Equipment Toggle memory are saved **per character**.
- Window position, scale, lock, flyout delay and the Equipment Toggle key live in a **profile**, which several characters can share.
- No libraries are embedded.

ForeverWeaponRack is not affiliated with WeaponRack by TooSoon. It was written from scratch and shares no code with it.
