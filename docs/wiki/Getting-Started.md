# Getting Started

> ForeverWeaponRack is **experimental**. See [[Home]].

This walks you through one set and one key. It takes about two minutes.

## 1. Open the window

Type `/fwr` or click the sword button on the minimap. The window has two tabs: **Edit Set** and **Sets**.

## 2. Make a set

On the **Edit Set** tab, click **Add Set**. The new set ("Set 1") starts with the weapons you're wearing right now.

## 3. Change what's in it

The four slots are Main Hand, Off Hand, Ranged and Ammo. Ammo only shows up when the Ranged slot holds a bow, gun or crossbow.

To put an item in a slot, do any of these:

- **Drag** it from your bags or the character sheet onto the slot.
- **Hover** over the slot for a moment. A list of items that fit pops out. Click one.
- **Left-click** a slot to pick its item up, then click another slot to drop it there. This is a fake cursor: the real item never leaves your bags.

**Right-click** a slot to change its state:

- **Item**: the swap equips this item.
- **Empty**: the swap unequips whatever is in that slot.
- **Leave alone**: the swap never touches that slot.

See [[Sets and Slot States]] for the details.

## 4. Save

Your changes stay a draft until you click **Save**. **Cancel** throws them away. Editing never equips anything.

## 5. Name it

Type a name in the **Name** box and click **Rename**. **Save as New** makes a copy under the new name instead.

## 6. Bind a key

Click the **Key** box. It says "Press a key". Press the key you want, for example `F`, `Shift-2` or Mouse 4. If something else already uses that key, you're asked first. See [[Key Bindings]].

## 7. Use it

Press the key. Your weapons swap. A green check on the slots and in the set list shows what you're wearing.

## Next steps

- Make a second set and give it the **same key** to flip between the two with one key. See [[Key Bindings]].
- Set up the [[Equipment Toggle]].
- On the **Sets** tab, reorder, copy, equip or delete sets.
