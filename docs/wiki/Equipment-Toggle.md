# Equipment Toggle

> ForeverWeaponRack is **experimental**. See [[Home]].

One key that takes your weapons off and puts them back.

- **If you're holding any weapon:** it unequips your **Main Hand, Off Hand and Ranged** and remembers exactly what was on. **Ammo and relics** (librams, idols, totems) are left alone.
- **If your hands are empty:** it puts the remembered items back, in the usual order (Main Hand → Off Hand → Ranged).

Use it to save durability before a wipe, for role-play, or anything else.

## Setting it up

1. Open **Settings**: the gear button in the window, `/fwr settings`, or Esc > Options > AddOns > ForeverWeaponRack.
2. Under **Equipment Toggle**, click the key box and press a key.

By default the key is stored in your **profile**, so every character on that profile shares it. Tick **Use a key for this character only** to give this character its own key. See [[Settings]].

## Good to know

- **The memory survives** a reload or logout.
- **Bag space:** you need one free bag slot per weapon taken off. If there isn't enough room, nothing moves and you get a "bags full" message.
- **Sold or banked items:** when you put your weapons back, anything you no longer have is skipped with a warning, and the rest goes back on. If nothing is left at all, the memory is kept, in case you get the items back from the bank.
- **The key is exclusive.** If a set uses the same key, that set loses it and shows "No key bound". See [[Key Bindings]].
- It follows the same rules as set swaps: it waits in the queue while you're dead or casting (and in combat, if the game turns out to block it). See [[Swapping]].
