# Settings

> ForeverWeaponRack is **experimental**. See [[Home]].

Open the settings with the **gear button** in the window header, **right-click** the minimap button, type `/fwr settings`, or go to **Esc > Options > AddOns > ForeverWeaponRack**.

| Setting | What it does |
|---|---|
| **Lock the window** | The window can't be moved or resized. The lock button in the window header does the same. |
| **Show minimap button** | Shows or hides the minimap button. The window still opens with `/fwr`, and from the add-on compartment if your client has one. |
| **Window scale** | Makes the window bigger or smaller (60% to 150%). |
| **Hover flyout delay** | How long you hover a slot before the item list opens (0 to 1.5 seconds). |
| **Equipment Toggle key** | Click the box and press a key. Right-click clears it. See [[Equipment Toggle]]. |
| **Use a key for this character only** | Off: the toggle key is stored in the profile and shared. On: this character has its own toggle key. |
| **Profile** | Which profile this character uses, plus **New**, **Delete** and **Reset**. |

## Profiles

A profile holds global settings only: window position, size, scale, lock, flyout delay, minimap button, and the Equipment Toggle key (unless set per character).

**Sets are never in a profile.** Each character owns different items, so sets, set keys and the Equipment Toggle memory always stay with the character.

- **New** asks for a name and starts the new profile as a copy of the current one.
- **Delete** removes the current profile and switches you to **Default**. Default can't be deleted.
- **Reset** puts the current profile back to the defaults.

## Window

- Drag the title to move the window. Drag the bottom-right corner to resize it.
- The close button and Escape close it. If you have unsaved item changes, you're asked whether to save them.
